# Contributing

Thanks for your interest in improving this toolkit.

1. Open an issue describing a bug or enhancement before large changes.
2. Create a branch from `main`.
3. Install locally: `python -m pip install -e '.[dev]'`.
4. Run `ruff check .` and `pytest -q`.
5. Submit a pull request explaining behavior changes and tests.

Please avoid adding real API keys, private datasets, or sensitive outputs.
